# 门槛分析口径

页面上的“门槛分析”不是把所有家庭合成一个全市平均效应。它只比较政策年龄门槛两侧、且资料截面和随访要求都满足的申请，分别给出：

- **资格带来的变化（ITT）**：申请当日年龄在门槛两侧时，60 天在园结局的跃迁。它回答“有资格”本身带来的差异，不要求家庭真的核销。
- **实际核销跃迁（first stage）**：门槛两侧实际核销比例的差。资格不等于核销；不完整依从下它是后续换算的分母。
- **实际核销的局部效应（LATE）**：结局跃迁除以核销跃迁，仅适用于门槛附近、因跨越门槛而改变核销行为的家庭。

三者都配 95% 区间与有效样本。区间使用 HC1 异方差稳健协方差；结局与核销跃迁联合估计，LATE 的区间用 delta 法计入两者相关，不把 first stage 当已知常数。

## 年龄与资料截面

- 年龄取 `age_history` 中 `visible_at <= policies.decision_vintage` 的最后版本，绝不使用事后订正或 `applications.age_days` 的较新值。页面会显示有多少条在截面之后被订正、若改用最新年龄会有多少条资格改变。
- 政策规则按 `policies.eligibility` 识别：严格小于时门槛位于 `cutoff-1` 与 `cutoff` 之间，小于等于时位于 `cutoff` 与 `cutoff+1` 之间。年龄恰等于门槛的记录按规则归侧，并在警告中列出条数。
- 资料截面之后才记录的申请（`recorded_at > data_cutoff`）不进入分析。
- `visit_60d=null` 或 `observed_days < 观察期` 的记录视为结局未成熟，从分析中排除，不会补 0。观察期可调，但不得低于政策规定的随访天数。

## 可调设置

| 设置 | 作用 |
| --- | --- |
| 分析窗口 | 门槛两侧各纳入多少年龄天数 |
| 边界排除（donut） | 排除紧邻门槛的若干天，检查测量或补登记造成的局部异常 |
| 实际入托观察期 | 结局成熟阈值；仅保留 `observed_days` 达到该值的记录 |
| 局部多项式阶数 | 线性或二次；阶数越高所需样本越多 |
| 核函数 | 三角核或均匀核，控制窗口内权重 |

所有设置由服务端重新计算；前端只展示服务端结果。

## 识别检查

分析结果附带四项检查，任一严重项不通过时页面停止输出 ITT/LATE，只保留描述：

1. **登记密度连续性**：以固定近门槛范围（不超过 ±60 天）的年龄分箱计数拟合 Poisson 模型，联合检验密度在门槛处是否跳变。p 小于 0.05 视为不连续，提示门槛附近可能存在补登记或排序。
2. **协变量平衡**：收入档、申请日、登记滞后和各中心占比在同一局部线性设定下检验门槛处跃迁；按检验数量做 Bonferroni 校正。未通过则两侧不具可比性。
3. **随访成熟度**：在门槛两侧比较结局成熟比例，p 小于 0.05 时视为不同风险集合。
4. **有效样本**：每侧至少 20（线性）或 30（二次）条、至少 5 个不同年龄取值，且等价核样本不少于 10。不足时只显示两侧描述。

此外 first stage 的 F 统计量低于 10 或核销跃迁小于 0.05 时，状态为“核销变化偏弱”：可报告资格差异与两侧核销比例，但不输出核销效应。

## 还能回答什么

识别条件不通过时，页面仍给出可核对的事实：门槛两侧的申请数、实际核销比例、成熟随访中的在园比例、年龄中位、登记密度分布、协变量检查与逐项排除计数。这些是描述值，不能读作补贴效果。

## 分析选择对照

“对照几种分析选择”会以当前设置为基准，依次运行半窗口、更宽窗口、排除边界、改变阶数、改变核函数和改变随访要求，列出每个规格的状态、有效样本、ITT、first stage 与 LATE。规格之间状态或区间不一致时，说明结论依赖这些假设，应向业务明确说明，而不是挑选单一结果。
