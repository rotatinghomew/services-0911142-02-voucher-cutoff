# 现场复核

先在画外完成依赖或镜像准备。服务就绪检查为 `/health`，启动不下载资料。打开首页，选择补贴年度，查看门槛两侧申请与实际核销记录；从任一明细点开原始记录核对。随后调整门槛分析的分析窗口、边界排除或观察期，运行门槛分析，查看估计、区间、有效样本、识别检查与门槛附近分布；点击“对照几种分析选择”查看结论依赖哪些假设；保存一次分析，改动设置后重开旧记录，确认保存的规格与结果没有随新设置变化，最后导出。

上述操作的设计时长为90至120秒，留出异常提示时间后不超过150秒。部署故障不隐藏也不回放旧结果。演示结果只来自本地虚构样例，具体状态与区间以页面当次计算为准；这里不预报方向，也不把任何单一规格当作业务结论。
